# 물지킴이 AI (AquaShield AI)
> **농업용 비료 유출 위험 모니터링 및 하천 수질 대응 웹앱 (교육·시연용)**

---

## 1. 프로젝트 개요

**물지킴이 AI**는 농경지에서 사용하는 질소 및 인 비료가 강우 및 배수를 통해 하천으로 유입될 때 발생하는 부영양화 위험과 수질 변화를 실시간으로 시각화하고, 비점오염 저감을 위한 최적관리방안(BMP), 비료 시비량 계산 및 수변 완충지대 설치 가이드를 제시하는 교육·시연용 웹 애플리케이션입니다.

사용자의 피드백을 반영하여 **3대 핵심 페이지 체제**로 확장 개편되었습니다:
1. **결과 및 맞춤 솔루션**: 수질 점수, 2가지 간략 솔루션, 비료 선택 및 필요 비료량 계산기.
2. **3D 하천 3구간 시뮬레이션**: 3구간(상류/가운데/하류) 3D 모델, 강우 발생기 및 상류 시비 강도 조절기, 구간 클릭 시 7대 정밀 지표 연동.
3. **완충지대 구조 및 설치 가이드**: 수변 완충지대의 비점오염 저감 효과, 적정 입지 기준, 3단계 단면 구조(Zone 1, 2, 3), 4단계 시공 가이드.

> **안내:** 본 시스템은 실제 하천 센서가 연결되지 않은 **가상 시뮬레이터 프로토타입**입니다. 화면에 표시되는 실시간 수질 데이터는 프로그램이 생성한 가상값(`SIMULATED`)이며, 실제 하천의 오염 진단이나 공공기관의 공식 수질 경보를 대체하지 않습니다.

## 2. 3대 핵심 페이지 구조

### 페이지 1: 결과 및 맞춤 솔루션 (`/results`)
- **[좌측] 수질 건전성 점수 (100점 만점) & 상태 진단**:
  - 수질 건전성 점수 게이지 (0~100점) 및 직관적 등급 배지 (`매우 양호`, `수질 주의`, `수질 위험`).
  - 감지된 주요 수질 지표 이상 요인 및 4대 핵심 지표 스냅샷.
  - 간이 모의 강우량 조절 슬라이더.
- **[우측] 2대 맞춤 솔루션 & 비료 필요량 계산기**:
  - **강우 및 현 상황 맞춤 솔루션 (2가지 간략 제시)**: 긴급 배수 관리, 논물꼬 상향 저류, 유출 차단 조치.
  - **현재 사용 중인 비료 선택**: 요소 비료, NPK 복합비료, 완효성 코팅비료(SRF), 유기질 유박비료, 발효 퇴비 중 선택.
  - **실시간 필요 비료량 계산**: 현재 강우량과 질산염 농도에 따른 권장 시비량(kg/10a), 감축률, 시비 시기 및 깊이 지침 출력.
  - **⚡ [이 솔루션 시뮬레이터에 적용] 버튼**: 원클릭으로 저감 대책을 실시간 엔진에 반영.

### 페이지 2: 3D 하천 3구간 시뮬레이션 (`/simulation3d`)
- **하천 3대 구간 3D 시뮬레이션 모델 (Three.js)**:
  - **① 상류 (농경지 유입구)**, **② 가운데 (중류 합류부 & 완충대)**, **③ 하류 (생태보호 유수지)** 3단계 명확 구분.
  - 360° 자유 회전, 줌 및 3구간 퀵 시점 전환.
  - **모의 강우 발생기 (0~80mm/h 슬라이더)** & **상류 시비 강도 (소량/적정/과다 토글)** 내장.
- **구간 클릭 연동 7대 상세 수질 지표 정밀 측정치**:
  - 상류/가운데/하류 중 원하는 구간을 클릭하면 해당 구간의 7개 지표(질산염, 인산염, 용존산소, 탁도, 수온, pH, 강우량)가 즉시 갱신 표시.
- **인터랙티브 시계열 차트 & 전체 이력 테이블 (CSV 다운로드)**.

### 페이지 3: 완충지대 구조 및 설치 가이드 (`/bufferzone`)
- **완충지대의 비점오염 저감 효과**: 질소 50~75% 저감, 인 60~85% 저감, 부유토사 70~90% 저감 정량 데이터.
- **완충지대 적정 설치 입지 기준 (어디에 설치할 것인가?)**:
  - 1) 농경지-하천 경계면 완경사지, 2) 배수로 말단 출구, 3) 축사·퇴비사 하류 사면, 4) 취수탑 상류 보호구역.
- **3단계 다층 단면 구조 설계도 (어떻게 설치할 것인가?)**:
  - **Zone 3 (농경지 인접, 2~4m)**: 초본 완충초지 (수크령, 물억새) - 초기 유속 지연 및 토사 1차 포집.
  - **Zone 2 (중간 완충, 3~5m)**: 관목 및 습지대 (갈대, 달뿌리풀, 부들) - 인산염 침전 및 생물학적 흡수.
  - **Zone 1 (하천 수변, 5~10m)**: 수변 수목대 (버드나무, 오리나무, 물푸레) - 심근성 지하수 질산염 탈질 및 제방 보호.
- **4단계 시공 및 사후 관리 가이드**: 사면 정비 → 초본 파종 → 수목 식재 → 연간 예초 부산물 수거.
- **정부 지원 사업 연계 안내**: 수계관리기금 토지매수 및 완충녹지 조성 국비 지원 사업 안내.

## 3. 기술 스택 및 실행 방법

### 기술 스택
- **3D Engine**: Three.js (r160+) with OrbitControls, PBR Materials & Custom Wave Geometry
- **Framework**: React 19 + TypeScript (Vite 번들러)
- **Styling**: Tailwind CSS v4 (`@import "tailwindcss";`)
- **Icons**: Lucide React
- **Architecture**: 서비스 계층(`services/`), 3D 렌더러(`River3DTelemetryViewer.tsx`), UI 모듈의 완벽한 분리

### 로컬 실행 방법
```bash
# 의존성 설치
npm install

# 개발 서버 실행 (포트 3000)
npm run dev

# 프로덕션 빌드
npm run build
```
